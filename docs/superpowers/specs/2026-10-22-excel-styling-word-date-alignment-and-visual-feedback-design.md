## 1. Problem Statement & Motivation

During operational use of the Doctors For You (DFY) HR Management Desktop application, three usability and document quality pain points were identified by the HR team:

1. **Unformatted & Plain Excel Exports**:
   - `excel_export_service.py` and `hr_report_exporter.py` produce bare DataFrames with no styling, no organization headers, raw unformatted numbers, default fonts, and no frozen header rows or auto-filters.
2. **Word Template Date Misalignment ("Date idhar-udhar ho ja rha hai")**:
   - In `document_generation_service.py`, reference numbers and dates are inserted using a hardcoded space string:
     `f"Reference No: {clean_ref}" + (" " * 81) + f"Dated: {clean_date}"`.
   - Because character length of reference numbers and dates vary (e.g. `DFY/HR/2026/0180` vs `DFY/HR/XXXX/PREVIEW`, `15 October 2026` vs `1 May 2026`), 81 spaces overflows the right page margin in Microsoft Word, causing the `Dated: ...` text to line-wrap to a second line or shift irregularly.
3. **Missing File Open / Browse Action for Exports**:
   - When a report (Candidate pipeline, overdue increments, certificates due, executive briefing, bulk ZIP) is exported, the app displays a text snackbar, requiring non-technical HR staff to manually navigate Windows File Explorer to find the file.
4. **Lack of Visual Output / Inspection on Spreadsheet Upload**:
   - When multi-sheet spreadsheets (like `PPSA INTERVIEW CHART.xlsx` with UP, Bihar, Maharashtra) are uploaded, users receive minimal visual confirmation of what was parsed, which sheets were found, and what candidates are about to be added.

## 3. Detailed Specifications

### 3.1. Professional Excel Export Styling Engine (`excel_export_service.py` & `hr_report_exporter.py`)

All Excel reports generated by the system will be transformed into executive-ready, branded workbooks using `openpyxl`:

1. **DFY Organization Header Banner**:
   - Rows 1–2 merged across all active columns.
   - Background fill: Dark Navy (`#0A2540`).
   - Title: Font `Segoe UI` / `Calibri`, 14pt, Bold, White (`#FFFFFF`), Left-aligned.
   - Text: `"DOCTORS FOR YOU — HR & RECRUITMENT OPERATIONS"`.
   - Row 3: Report Name & Metadata (e.g. `Report: Candidate Pipeline | Generated: 22-Oct-2026 13:30 | Confidential`), Italic, 10pt, Navy text (`#1E3A8A`) or Subtext gray (`#475569`).
2. **Table Header Row (Row 5)**:
   - Background fill: Corporate Blue (`#1E3A8A`).
   - Font: White (`#FFFFFF`), 11pt, Bold, Centered vertically and horizontally.
   - Row height: `26pt`.
   - Thin bottom border: `#CBD5E1`.
   - OpenPyXL Auto-Filter enabled on `A5:<LAST_COL>5`.
   - Freeze Panes enabled on cell `A6` so header remains visible during vertical scrolling.
3. **Data Rows & Zebra Striping**:
   - Alternating fills: Even rows `#FFFFFF`, Odd rows `#F8FAFC`.
   - Thin borders around all cells: `Side(style='thin', color='E2E8F0')`.
   - Row height: `20pt`.
4. **Data-Type Aware Formatting**:
   - **Currency / Salary Columns** (`Salary`, `Negotiated Salary`, `Revised Pay Grade`, `Gross Salary`):
     Formatted as Indian Rupees `₹ #,##,##0` or `₹ #,##0`. Right-aligned or Centered.
   - **Date Columns** (`Date Joined`, `Relieving Date`, `Archived At`, `Timestamp`, `Generated Date`):
     Formatted as `DD-MMM-YYYY` (e.g. `15-Oct-2026`). Center-aligned.
   - **Identifiers & Status** (`Mobile`, `Status`, `Emp ID`, `Priority #`):
     Center-aligned.
   - **Names & Text** (`Candidate Name`, `Applied Designation`, `Department`, `Location`, `Guidance`):
     Left-aligned with left indent of 1 space.
5. **Auto-Fitted Column Widths**:
   - Auto-calculate max length of cell contents + 4 characters padding.
   - Bound column widths between minimum `14` and maximum `55`.

### 3.2. Word Template Header Date Alignment Fix (`document_generation_service.py`)

#### Root Cause:
`insert_reference_and_date` currently relies on hardcoded string padding:
```python
text = f"Reference No: {clean_ref}" + (" " * 81) + f"Dated: {clean_date}"
```
In Word's layout engine, variable-length text with 81 space characters wraps onto a second line, breaking document headers.

#### Robust Solution:
Replace paragraph string insertion with a native **1-row, 2-column borderless Word table**:
1. Insert a 1x2 table directly below the top anchor/logo paragraph (`doc.paragraphs[0]`).
2. **Table Geometry & Layout**:
   - Width: `100%` of margin width (`Inches(6.5)` on standard letter/A4 with 1-inch margins).
   - Column 0 (Left): Width `55%` (`Inches(3.6)`).
   - Column 1 (Right): Width `45%` (`Inches(2.9)`).
   - Borders: Zero borders (`val="none"` on top, bottom, left, right, insideH, insideV).
   - Cell margins / padding: `0` top, bottom, left, right to preserve exact baseline alignment.
3. **Content Formatting**:
   - **Left Cell (`cell[0]`)**:
     - Text: `Reference No: {clean_ref}`
     - Alignment: Left (`WD_ALIGN_PARAGRAPH.LEFT`)
     - Font: Times New Roman, 11pt (12pt for Experience/Salary Certificates), Bold.
   - **Right Cell (`cell[1]`)**:
     - Text: `Dated: {clean_date}` (or `Date: {clean_date}`)
     - Alignment: Right (`WD_ALIGN_PARAGRAPH.RIGHT`)
     - Font: Times New Roman, 11pt (12pt for Experience/Salary Certificates), Bold.
4. **Guarantee**:
   Because cell 0 is left-aligned and cell 1 is right-aligned inside a fixed 100% width table, `Reference No` and `Dated: ...` will ALWAYS sit on the exact same horizontal baseline at opposite margins with ZERO chance of wrapping or drifting.
5. **Body Date Normalization**:
   Ensure `format_date_long` and `calculate_end_date` in `document_formatters.py` cleanly handle all input date types (strings, datetime, date, pandas Timestamp) without producing `None` or time suffixes (`00:00:00`).

### 3.3. OS File Launcher & Reusable Export Success Modal (`file_launcher.py` & `ui_theme.py`)

A new utility module `desktop_app/utils/file_launcher.py` will provide native OS execution helpers:
```python
def open_file_externally(file_path: str) -> Tuple[bool, str]:
    """Opens file using the default OS application (e.g. MS Excel for .xlsx)."""
    if not os.path.exists(file_path):
        return False, "File not found"
    os.startfile(os.path.abspath(file_path))
    return True, "File opened"

def open_folder_and_select(file_path: str) -> Tuple[bool, str]:
    """Opens Windows Explorer highlighting the exported file."""
    if not os.path.exists(file_path):
        return False, "File not found"
    subprocess.Popen(f'explorer /select,"{os.path.abspath(file_path)}"')
    return True, "Folder opened"
```

#### Export Success Dialog:
When any export action completes:
- Render an `ft.AlertDialog`:
  - **Title**: `ft.Row([ft.Icon(ft.Icons.CHECK_CIRCLE, color=COLOR_SUCCESS), ft.Text("Export Complete")])`
  - **Content**: Card showing:
    - File Name: `candidate_pipeline.xlsx`
    - Destination: `desktop_app/output/candidate_pipeline.xlsx`
    - Stats: `44 Records • 38.4 KB`
  - **Action 1**: `ft.ElevatedButton("📄 Open Excel File", on_click=lambda e: open_file_externally(path))`
  - **Action 2**: `ft.OutlinedButton("📁 Open Folder", on_click=lambda e: open_folder_and_select(path))`
  - **Action 3**: `ft.TextButton("Close", on_click=lambda e: page.close(dlg))`

### 3.4. Inline Multi-Sheet Visual Preview on Excel Upload (`joining_process_page.py`)

When an Excel spreadsheet is uploaded in the Candidate Joining Process page:

1. **Pre-Ingestion Visual Review State (`view_mode == "upload_preview"`)**:
   - **Sheet Switcher Tabs**:
     If multiple sheets exist in the uploaded file (e.g., `PPSA UP (11)`, `PPSA Bihar (14)`, `PPSA Maharashtra (19)`), render an `ft.Tabs` or segmented filter row allowing user to toggle between sheets.
   - **Visual KPI Strip**:
     - `📊 Total Rows Extracted: 44`
     - `✨ Genuinely New: 43`
     - `🔄 Existing / Duplicates: 1`
     - `✅ Column Health: 11/11 Columns Mapped`
   - **Interactive Live Preview DataTable**:
     - Displays the first 10 candidate rows from the selected sheet with:
       `Candidate Name | Mobile | Applied Role | Offered Salary | Location | Status`
     - Shows visual badges for missing or warning fields.
   - **Primary Action Buttons**:
     - `🚀 Confirm & Ingest Candidates (44)`: Commits records to the database.
     - `❌ Cancel`: Clears staging without touching the database.
2. **Post-Ingestion Completion Badge**:
   - Replaces the preview with a prominent success banner:
     - `🎉 Ingested 44 candidates across 3 sheets (43 New, 1 Updated).`
     - Direct quick-action pills:
       - `[✉️ Review Welcome Emails (43)]`
       - `[👥 View In Pipeline]`
